## 二、系统架构图

放正式架构图，按层次标注：

```
[ 接入层 ]  扫码入口 / Web 前端 / 移动端
      │
[ 编排层 ]  意图与现象抽取 → 安全前置判断 → 检索 → 分级决策 → 输出组装 → 工具调用
      │
[ 检索层 ]  文档切分 → 向量索引 + 关键词索引 → 混合召回 → 重排 → 置信度评估
      │
[ 模型层 ]  大模型 API / 本地模型（含降级备用）
      │
[ 工具层 ]  工单生成 / 台账写回 / 消息推送
      │
[ 存储层 ]  知识库 / 会话记录 / 工单表 / 待补充问题清单
```

配文说明每一层的技术选型与选型理由（选型理由是技术性得分点，别只写选了什么）。

## 三、核心逻辑说明

### 3.1 处理流程（分步，标明输入输出）

| 步骤 | 输入 | 处理 | 输出 |
| --- | --- | --- | --- |
| 1 现象抽取 | 用户自然语言 + 设备上下文 | 结构化抽取 | JSON（报错码/部位/现象/是否带电） |
| 2 安全前置 | 步骤 1 输出 | 高危规则匹配 | 是否立即拦截 |
| 3 检索 | 结构化查询 | 混合召回 + 重排 | Top-K 片段 + 出处 + 置信度 |
| 4 分级决策 | 检索结果 + 安全判断 | 规则 + 模型 | 授权等级 A/B/C |
| 5 输出组装 | 以上全部 | Schema 约束生成 | 分步方案 + 引用 + 是否开工单 |
| 6 工具调用 | 步骤 5 输出 | 调用外部接口 | 工单号 / 推送结果 |

### 3.2 分级授权规则

| 等级 | 判定条件 | 输出策略 |
