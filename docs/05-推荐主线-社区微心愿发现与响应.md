# 推荐主线（升级版）：社区微心愿的「发现—代言—响应」闭环

> 本文取代 `docs/01` 中的主线 A（实训室数字化）成为首选方案。
> 原始想法（每天发心情 → 分析需求 → 让关心他的人圆梦）的**立意保留**，**机制重做**。

## 一、对原始想法的诚实评估

### 立意极强，几乎是照着评审口味长出来的

| 依据 | 出处 |
| --- | --- |
| 赛道二推荐主题(5)「弥合鸿沟·暖心伴行」原文点名孤寡老人、留守儿童，并写明目标是「**提升特殊群体的生活便利度与幸福感**」 | 原文第 9–10 页 |
| 赛道二推荐主题(6)「互联微光·数智日常」记录普通劳动者、社区居民改善生活质量的微创新案例 | 原文第 10 页 |
| 赛道三推荐主题(1)「数智政务·服务帮手」结合「高效办成一件事」改革，做智能导办与**政策精准推送** | 原文第 10 页 |
| 赛道三推荐主题(4)「数智健康·民生守护」、(5)「虚实共生·多态交互」（无障碍交互） | 原文第 11 页 |
| **民政厅、团省委、总工会** 均为主办单位——养老、社会救助、志愿服务、困难帮扶正是其职责范围 | 原文第 3、5 页 |
| 奖项说明：优秀作品纳入平台面向社会专题展示，具备转化条件的**优先成果孵化** | 原文第 14 页 |

「获得感、幸福感」这两个词不是空话——湖南省委组织部对三长制成效的官方表述就是「明显提升了群众的幸福感和获得感」。这条线的话语体系和评审的话语体系是同一套。

**结论：立意比实训室主线高一个档次。** 上一版我用「可交付性」换了「立意」，这一版用下面的建制单元设计把可交付性补回来，不必再取舍。

### 但原始机制有三个会致命的硬伤

**硬伤 1：「让关心他的人去帮他圆梦」是典型的双边冷启动难题。**

需求侧容易有，供给侧从哪来？如果是亲友，微信就够了，产品没有存在价值；如果是陌生志愿者，就需要真实的组织、审核、履约、追责机制。4 天内建不出来，没有真实供给方，作品就是一个空壳界面。

**评委必问的一句话：「有多少个心愿真的被实现了？」** 答不出这个数字，实用性（赛道二 35% / 赛道三 20%）直接崩盘。

**硬伤 2：中老年人不会每天发心情。**

「每天打卡记录情绪」是年轻人的产品习惯。让老人每天主动选表情、写心情，日活撑不过一周，而且这恰恰把「不会用、不想用」的数字鸿沟又加深了一层——与作品立意自相矛盾。

**硬伤 3：从「心情」推「需求」这条链路在方法上很脆，技术含量也不够。**

情绪分类是成熟到烂的任务，调个 API 就有，撑不起赛道三的技术性 25%。而且评委一问「凭什么从『今天有点累』推出他需要一台收音机」，就答不上来。

### 另外两个必须绕开的坑

- **心理/情绪数据是内容安全高压区。** 原文「四、确保安全有序」要求提高风险防范意识、加强内容审核、确保导向正确。识别出自伤倾向而处理不当是重大风险。
- **不要做公开许愿池。** 把弱势群体的困境挂出来供人围观，伦理上不妥，也容易被评委质疑「消费苦难」。

## 二、机制重做：三个事实改变了产品形态

我核实了两条湖南本地事实，它们直接把上面的硬伤解掉了。

### 事实 1：供给侧和派单渠道都已经存在

- **湖南「三长制」**：省委组织部在全省推行片长、组长、邻长体系，**相邻居住的 5–15 户为 1 邻**，邻长由群众推选的居（村）民代表担任，职责就是民情联络，并建立「发现、反映、解决、反馈」闭环。仅长沙市就有 1.02 万名片长、3.78 万名组长、**23.48 万名邻长**，2023 年以来摸排问题 58.04 万个、提供「微服务」45.32 万件。
- **湖南志愿服务网**：全省统一平台，省市县三级权限，具备志愿者注册、服务记录、**时长统计**、表彰激励功能；全省志愿者 1530 余万名、团队 7.7 万个；已有「群众点单、平台派单、志愿者接单」模式与积分星级激励。

**所以「关心他的人」根本不用你去找——23 万名邻长和 1530 万志愿者已经在那里了。** 双边冷启动难题消失。

### 事实 2：现有体系的真正短板，正是你直觉抓到的那个词

那套「点单—派单—接单」的闭环，只服务**会点单的人**。而真正需要帮助的人：不知道能点单、不会操作、更重要的是**不肯开口**（「不想麻烦别人」是中老年人最典型的心理）。

**你说的「无人问津」，恰恰命中了这个空白。**

### 由此得到的产品定位（这是最关键的一句）

> **产品的核心不是「帮我圆梦」，而是「发现那些还没开口的人」。**

不做又一个许愿池 App，做现有治理体系缺失的那一层——**发现层**。

### 事实 3：「一个邻」是一个标准建制单元

5–15 户为 1 邻，这是省委组织部的制度设定。意味着你在 4 天内做 10–15 户的完整闭环，**不是「样本太小」，而是「完整覆盖了一个标准建制的邻」**。这句话能直接回应评委「你才做了十几户是不是太少」的质疑。可交付性问题就此解决。

## 三、产品设计：《邻声 · 社区微心愿发现与响应系统》

命名建议用「微心愿」「微服务」（三长制官方用词），比「圆梦」更接地气、更契合基层治理话语，也不会给人过度承诺的印象。

### 三层架构

```
┌─ 发现层（核心创新，现有体系的空白）
│    入口 1：老人自己说一句话（语音优先、方言容错、不强制、不打卡）
│    入口 2：邻长走访时代录（主力入口——邻长本来就要走访并填民情台账）
│    入口 3：存量信号（走访间隔、社区食堂/活动参与、子女来电频次…有多少用多少）
│         │
│         ▼  自然语言三层抽取：情绪状态 / 显性需求 / 隐性需求
│         ▼  静默指数（"无人问津度"）多信号时序计算
│
├─ 代言层（尊严设计）
│    需求默认不公示，先交邻长核实，由邻长"代为提出"
│    大心愿拆解为可被一名志愿者一次履约的最小单元
│    风险分级：红 / 黄 / 绿
│
└─ 响应层（对接存量供给，不另建孤岛）
     派单给邻长 / 片长 / 社区志愿队 / 爱心商户
     履约打卡 → 回访确认 → 志愿时长自动统计（可导出报湖南志愿服务网）
```

### 四个真正有创意的设计决策

**1. 静默指数（无人问津度）——把「发现」变成可计算的指标**

多信号时序融合：主动发声频次下降、走访间隔拉长、社区活动参与减少、子女联系频次下降、心愿被响应次数为零。指数越高越靠前，自动推到邻长待办列表首位。

这一项把作品从「等人许愿」升级为「主动发现」，是全作品最有社会治理价值、也最有技术含量的功能（多信号异常检测，而非简单情绪分类）。

**2. 需求代言机制——针对「不想麻烦别人」的心理设计**

系统识别出需求后不直接公示，先转邻长核实，由邻长以自己的名义提出。老人不必开口求助，尊严得以保全。这是真正理解目标用户的设计，也是评委很难在别的作品里看到的。

**3. 心愿拆解为最小可履约单元——让闭环真的转起来**

「我想再看看老家」→ 拆成「帮拍一段老家的视频」；「想吃女儿做的饭」→ 拆成「邻长送一次家常菜 + 一次视频通话」。降低供给门槛是闭环能否运转的关键，也是把「圆梦」这个口号变成可交付物的唯一办法。

**4. 相当一部分「心愿」其实是政策没送达**

老人的需求里有很大比例不需要慈善，需要的是**知道自己有权利享受什么**：高龄津贴、居家养老服务补贴、助餐补贴、慢病用药报销、家庭医生签约、适老化改造补贴。

Agent 用 RAG 检索惠民政策库，直接告出「你符合 XX 条件，需要这几样材料，找谁办，多久办完」。这一步把作品从「做好事」提升为**公共服务精准化**，正好对上赛道三主题(1)「结合『高效办成一件事』改革，开发智能导办与政策精准推送」的原文表述。站位高得多。

### 风险分级（把最大的风险点做成卖点）

| 等级 | 触发条件 | 处置策略 |
| --- | --- | --- |
| **红** | 自伤/自杀倾向、疑似重病、独居失联、疑似诈骗 | **AI 绝不自行安慰或作答**，立即升级片长 + 家属 + 社区，全程留痕 |
| 黄 | 情绪持续低落、显性困难（就医、维修、代购、办事） | 生成心愿派单，邻长核实后响应 |
| 绿 | 日常陪伴、兴趣需求 | 进心愿池，志愿者认领 |

红码强制转人工是这个作品必须有的设计。做了它，情绪数据的安全风险就从减分项变成了创新性与完整性的加分项——因为它证明你想清楚了边界。

## 四、拆成两件作品

### 作品 1｜赛道二 · 数字工具应用：《一本民情台账的数字化改造》

- 归口主题：**弥合鸿沟·暖心伴行**（兼 智慧办公·管理赋能）
- **不要做 App。** 赛道二原文限定「通用数字工具（办公软件、协作平台、移动应用及轻量级 AI 工具）」，自研 App 投赛道二属于偏题。

| | 使用前 | 使用后 |
| --- | --- | --- |
| 走访记录 | 纸质民情台账手写 | 扫码填表单，语音转文字自动抽取需求 |
| 数据汇总 | 片长月底手工汇总 | 多维表格自动成表，一户一档 |
| 走访提醒 | 靠记性 | 按三长制制度要求自动提醒（重点户每周≥1 次、普通户每月≥1 次） |
| 心愿管理 | 记在本子上 | 心愿池自动生成，认领与履约打卡 |
| 谁最需要关注 | 凭印象 | 静默指数看板自动排序 |
| 志愿时长 | 事后凭回忆填 | 自动统计，可导出上报 |

前后对比指标（实用性 35% 的主战场，必须实测）：单户走访记录耗时、月度台账汇总耗时、**走访覆盖率/遗漏户数**、心愿平均响应时长、心愿实现率、志愿时长统计耗时与准确率、高风险户发现提前天数。

其中「走访覆盖率」特别有说服力——三长制本身有明确的走访频次制度要求，系统把制度要求变成可量化的达成率，这是治理指标而不仅是效率指标。

### 作品 2｜赛道三 · 智能体创新：《邻声智能体》

- 归口主题：可同时挂 **数智政务·服务帮手**（政策精准推送）+ **数智健康·民生守护** + **虚实共生·多态交互**（语音无障碍）

| 模块 | 技术点 |

| 语音入口 | 语音识别 + 方言容错 + 适老无障碍交互（多模态） |

## 五、4 天内的落地路径（这是唯一的真风险）

必须真的服务几户人，拿到「N 户覆盖、M 个心愿实现、K 次预警命中」这三个数字。按可行性排序：

1. **首选：学校离退休处 / 离退休教职工党支部。** 学校本来就有离退休教职工管理部门，有名单、有联系方式、有走访制度，沟通成本最低，当天就能对接。取 10–15 户 = 一个标准邻。
2. **次选：学校所在社区居委会。** 直接说明是省级大赛作品、免费为社区做一个邻的数字化台账，并留下可继续使用的模板——社区通常愿意配合。
3. **兜底：学生分头回家做。** 每位学生负责自家及邻居 2 户，一个班就能覆盖几十户，且天然覆盖城乡不同场景。这个方案的额外好处是把「学生用数字技能服务家乡长辈」本身变成作品叙事。

## 六、伦理与合规红线（必须写进材料）

1. **知情同意**：每户签知情同意书，老人不便时由子女代签；材料中出现的姓名一律化名，人脸打码。
2. **敏感信息处理**：情绪与健康信息属敏感个人信息，说明存储范围、可见范围（默认仅邻长/片长可见）、保存期限。
3. **红码不自答**：自伤/自杀信号绝不由 AI 处理，硬编转人工 + 留痕 + 通知，处置流程写进技术文档。
4. **不做医疗或心理诊断**，全程免责声明。
5. **不做公开许愿池**：对外可见的是「可认领的服务任务」，而不是「某人有多困难」。
6. **履约真实性核验**：回访确认 + 双方签认，防止骗捐与营销滥用（原文明令「严禁营销炒作、弄虚作假」）。
7. **AI 生成内容显著标识**：视频角标 + 文档声明 + 图片水印。

## 七、湖南辨识度（免费的加分项）

- 对接「片组邻」三长制，直接使用「邻」「微服务」「民情台账」等官方话语
- 湖南是**雷锋家乡**，志愿服务是本省最强的文化叙事资产；对接湖南志愿服务网的时长记录与星级激励，作品就接上了「雷锋家乡的志愿者」这条线
- 团省委、民政厅、总工会都是主办单位，志愿服务、养老救助、困难帮扶三条线都能对上

## 八、其他社会治理方向（备选，不如上面这条）
