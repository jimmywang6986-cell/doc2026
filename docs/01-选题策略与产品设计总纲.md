# 选题策略与产品设计总纲

## 一、先把评分表读成产品需求

这次比赛不是「谁的技术强谁赢」，两个赛道的评分结构完全相反，必须分开设计。

### 赛道二：实用性 35% 是绝对大头

权重是 实用 35 > 创新 20 = 技术 20 > 完整 15 > 规范 10。而实用性的评分说明写得极具体：**"解决实际痛点的有效性、'使用前'与'使用后'对比成效"**。

这意味着：

- **赛道二的胜负不在做了什么，而在能不能拿出一张可信的前后对比数据表。** 有真实计时、真实差错率、真实成本的作品，哪怕技术上只是「表单 + 二维码 + 自动汇总」，也能压过一个花哨但成效说不清的作品。
- **技术越"普通"越对味。** 赛道二定位原文限定为「通用数字工具（办公软件、协作平台、移动应用及轻量级 AI 工具）」，主题是「提升全民数字素养」「构建普惠包容数字社会」。在这里堆自研系统属于偏题——评委要看的是普通劳动者能照着学会的实操方案。
- **推论：不要自己写代码。** 用 WPS/Excel、飞书多维表格或钉钉宜搭、腾讯文档、微信/问卷表单、二维码工具、剪映这类零门槛工具。作品形式原文也已指定为「实操录屏 + 真人解说」视频、图文操作手册、流程对比报告。

**反向推导出的选题约束：必须选一个"使用前"数据现在就能拿到手的场景。** 这一条会直接淘汰掉大部分看起来更"高大上"的题目——你没法在 4 天内补出一个工厂产线的历史工时台账，但你能在半天内翻出实训室的纸质点检表、教研室的 Excel 汇总表、微信群里的收作业记录。

### 赛道三：技术 25% + 创新 25% 占一半

权重是 技术 25 = 创新 25 > 实用 20 = 完整 20 > 规范 10。技术性评的是「技术实现难度、系统架构合理性、代码/配置质量」。

这意味着：

- **必须有真东西。** 一个只配了几句提示词的对话机器人在技术性上拿不到分。至少要具备下列之一并讲清楚：检索增强（RAG）、工具调用/函数调用、多步工作流编排、多模态输入。
- **"可运行"是入场券，不是加分项。** 原文明确要求可安装/运行、提供测试账号或完整配置说明、低代码交导出文件或完整配置截图、编程交核心源代码。这些是规范性 10% + 完整性 20% 里白给的分，漏一样都可惜。
- **技术文档三件套是硬性列举项**：系统架构图、核心逻辑说明、提示词（Prompt）设计。这条被单独写进作品形式要求，说明评委会照着找。
- 复评「视情况进行线下答辩、场景模拟演示」→ 架构要能当场跑，别依赖不稳定的外部依赖。

### 两个赛道的产品形态因此是互补的，不是同一件事的两种包装

| | 赛道二 | 赛道三 |
| --- | --- | --- |
| 解决的问题类型 | 流程慢、重复劳动、信息汇总难 | 知识查不到、判断不会做、门槛高 |
| 交付物 | 实操录屏 + 图文手册 + 前后对比报告 + 《应用说明书》 | 可运行程序 + 演示视频 + 技术文档（架构图/逻辑/Prompt）+ 源码或导出文件 |
| 技术姿态 | 越通用、越可复制越好 | 越有实现难度、架构越清晰越好 |
| 核心证据 | 一张真实的前后对比数据表 | 一个当场能跑起来的系统 |

## 二、时间现实：今天到校内截止只有 4 天

今天 8 月 21 日，校内截止 8 月 25 日，省赛截止 8 月 31 日。这个时间盘决定了三件事：

1. **选题必须落在"你已经拥有领域知识和历史数据"的场景里。** 田野调研的时间不存在了。
2. **两件作品必须共用一条场景主线**，共享同一批访谈、素材、录屏环境、视觉风格，否则做不完两套材料。
3. **先抢不可逆的素材。** 「使用前」的证据（纸质表格照片、原始 Excel、旧流程的计时录屏、当事人原话）一旦你把新流程上线了就再也补拍不到了。这是 Day 0 的第一优先级，比搭工具更急。

## 三、三条候选主线的取舍

我按「4 天内可交付」× 「评分权重契合度」× 「撞车风险」评估了三条主线。

### 主线 A：职业院校实训与实习的数字化（推荐）

- 赛道二 → 实训室设备点检 / 顶岗实习周报的零代码流程改造
- 赛道三 → 实训设备故障排查与安全规程的 RAG 智能体

**优势**：
- 「使用前」证据唾手可得——纸质点检表、Excel 汇总、微信群催报，都在手边，可信度高且能拍到原始凭证。
- 契合湖南「三高四新」语境（工程机械、轨道交通是原文点名的产业），而承办单位里就有湖南铁道职业技术学院、湖南工业职业技术学院，说明主办方认这个场景。
- 教师组评审要点是「减轻教师负担的实际效果」，实训与实习管理正是教师最真实的负担来源，比「AI 备课」更少人做。
- 两件作品构成叙事闭环（点检发现异常 → 智能体指导处置），但交付物零重叠。

**风险**：需要实训室或实习管理岗老师配合提供台账；设备手册若无电子版，需要扫描后再灌知识库。

### 主线 B：弥合数字鸿沟（备选，宣传价值最高）

- 赛道二 → 「长辈手机课」：智慧就医、医保码、反诈设置的实操手册 + 录屏，请 3–5 位老人实测
- 赛道三 → 适老多模态办事陪伴智能体（语音优先、方言容错、危险操作拦截）

**优势**：
- 主办方是网信办，主题词是「普惠包容数字社会」，原文两个赛道都列了关爱类主题（赛道一「温情守护·关爱同行」、赛道二「弥合鸿沟·暖心伴行」）。奖项说明里还写了优秀作品纳入平台面向社会专题展示、优先成果孵化——有温度的作品在展示环节占便宜。
- 「体验对比」可以做得非常有说服力：老人首次独立完成率、耗时、求助次数。
- 测试对象比工厂数据更容易找（社区、自家长辈）。

**风险**：赛道三这一侧要靠多模态才撑得起技术性 25%，4 天内做稳定的语音链路有翻车风险；现场演示对麦克风环境敏感。

### 主线 C：智慧教育·教学减负 + 数智伴学·教育助教（不推荐作为主线）

契合度看似最高（原文两个赛道都有对应主题），但这是全省撞车最严重的赛道——「AI 备课助手」「AI 作业批改」「AI 学情分析」几乎必然出现大量同质作品。创新性占赛道二 20%、赛道三 25%，同质化会被直接压分。

**如果一定要做教育场景，就把切口收窄到别人不会做的环节**：不做「备课」，做「跨学科教研的协同」；不做「批改」，做「实训报告的过程性评价」。

## 四、明确不建议做的题目

| 题目类型 | 原因 |
| --- | --- |
| AI 备课 / AI 批改 / AI 写作助手 | 撞车最严重，创新性直接失分 |
| 数字人主播 / AI 短视频生成 | 属于赛道一（数字文创设计）的地盘，投赛道二会被认为工具驾驭深度不足，投赛道三缺乏系统性 |
| 心理疏导 / 心理陪伴智能体 | 组委会反复强调「加强内容审核」「确保导向正确、安全有序」，内容安全风险高，4 天内做不出可交付的安全护栏 |
| 医疗问诊类智能体 | 同上，且资质敏感；原文虽列了「远程问诊导诊」，但学生/教师作品难以规避误导风险 |
| 通用「大而全」平台 | 实用性无法用前后对比量化，技术性也做不深，两个赛道都吃亏 |

## 五、最终推荐组合

**主线 A**，两件作品如下（详见后续两份方案文档）：

- **作品 1｜赛道二·数字工具应用**：《扫码点检 · 台账即时成表》— 实训室设备与耗材管理的零代码数字化改造
- **作品 2｜赛道三·智能体创新**：《实训安全与故障排查智能体》— 面向职业院校实训场景的 RAG + 工单 Agent

如果实训室资源拿不到，整体平移到 **主线 B**，作品骨架和材料清单完全复用。

两件作品的分工可以用一句话概括：**赛道二把"人做流程"变快，赛道三把"人做判断"变准。**
